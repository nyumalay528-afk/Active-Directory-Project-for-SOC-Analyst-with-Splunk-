# Phase 5: Attack Simulation & Detection

## Objective

Simulate a real attack against the Windows target, then use Splunk to detect and analyze it — the "blue team" payoff of the whole lab.

## Part A: RDP Brute-Force Attack

**Setup**

- Configured Kali Linux with a static IP (`192.168.10.250`).
- Installed and configured Hydra for RDP authentication testing.
- Built a password list for the test account.
- Enabled RDP on the Windows target (`192.168.10.100`) and confirmed that RDP was listening on port `3389`.
- Verified connectivity between Kali and the Windows target before starting the attack.

**Attack**

```bash
hydra -l administrator -P uu.txt rdp://192.168.10.100
```

- Ran the attack from Kali against the Windows target over RDP.
- Generated repeated authentication attempts against the `administrator` account.

**Detection (Splunk)**

```spl
index="endpoint" EventCode=4625 src_ip=192.168.10.250 Account_Name=administrator
| stats count by Account_Name, src_ip
| sort - count
```

- Confirmed a burst of `EventCode=4625` (failed logon) events generated by the RDP brute-force activity.
- Identified the Kali machine (`192.168.10.250`) as the source of the failed authentication attempts.
- Observed `103` failed logon events for the `administrator` account.
- This demonstrated the complete attack-to-detection workflow: Kali attack → Windows authentication telemetry → Splunk detection.

## Part B: Atomic Red Team (ART) Telemetry

**Setup**

- On the Windows target: configured PowerShell execution policy, installed the Atomic Red Team framework, and prepared the environment for ATT&CK-based testing.

**Execution**

- Ran ART tests mapped to MITRE ATT&CK techniques, including:
  - T1136 — Create Account
  - T1059 — Command and Scripting Interpreter

**Detection (Splunk)**

- Searched `index=endpoint` for Sysmon EventCode 1 (process creation) and Windows Security EventCode 4720 (user account created).
- Used the generated telemetry to verify that the Atomic Red Team tests were visible in Splunk.

## Cleanup

- Took a VirtualBox snapshot of the environment after the attack simulation for easy rollback and re-testing.
